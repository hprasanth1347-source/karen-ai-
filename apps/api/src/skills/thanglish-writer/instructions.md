# Thanglish Writer Skill

Use this playbook to rewrite or draft messages, captions, or replies in natural Thanglish (Tamil + English), Tamil, or English with tone control (casual, respectful, professional, warm).
- Keep Thanglish natural and readable (e.g., "Seri da", "Naan check panni solluren", "Bro, details anuppitten").
- Never mix in robotic literal translations.
