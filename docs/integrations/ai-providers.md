# AI Providers Setup Guide (Groq & Gemini)

## Groq Cloud (Ultra Fast Llama 3.3)
1. Register at https://console.groq.com
2. Navigate to **API Keys** and generate a new key.
3. Paste into `GROQ_API_KEY` in `.env`.
4. Model used: `llama-3.3-70b-versatile`.

## Google Gemini 2.0 Flash
1. Go to Google AI Studio: https://aistudio.google.com
2. Create an API Key.
3. Paste into `GEMINI_API_KEY` in `.env`.
4. Model used: `gemini-2.0-flash`.

## Language Strategy
Karen Ultra is system-prompted to respond in natural **Thanglish** (Tamil words transliterated into English/Latin script mixed with conversational English) by default, providing friendly and highly accessible assistance.
