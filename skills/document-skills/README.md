# Anthropic Document Skills

This directory contains the Apache-2.0 licensed document skills copied from:

https://github.com/anthropics/skills

Included skills:

- `docx` - create, edit, inspect and validate Word documents
- `pdf` - extract, merge, split, rotate, watermark and analyze PDFs
- `pptx` - create, edit, inspect and validate PowerPoint presentations
- `xlsx` - create, edit, inspect and recalculate Excel workbooks

The files in this directory are instructions and helper scripts. Karen exposes the skill metadata through `/api/v1/skills/document`; helper scripts are not executed automatically.
